# 테스트 기록: Echo 연결 종료와 원시 TCP 바이트 진단 (기존 자료 이관)

- 작업일: 2026-09-15 (자료 정리)
- 버전 폴더: 001
- 이전 버전과의 차이: 기존 build 자료를 최초 보관 버전으로 이관했다. 실행별 과거 버전은 미확인이다.

## 1. 테스트 목적

Echo 연결 종료와 원시 TCP 바이트 진단 자료를 재현 및 분석에 활용할 수 있도록 보존한다. 이번 작업은 자료 이관이며 원래 기능을 다시 테스트하지 않았다.

## 2. 테스트 대상

- 대상 기능: Echo 연결 종료와 원시 TCP 바이트 진단
- 대상 코드: [README의 이동 목록](../README.md) 참조. 개별 실행과 코드 버전의 정확한 대응은 미확인이다.
- 관련 버그: 개별 원본 로그 참조. 이번 이관에서는 원인 분석을 수행하지 않았다.
- 관련 변경 사항: 파일 위치만 변경했다. 원본 스크립트 및 로그 내용은 유지했다.

## 3. 테스트 환경

- 환경: Windows, PowerShell. 과거 실행의 상세 환경은 원본 로그 참조.
- 버전 / 커밋: 원본 자료에 기록된 값만 유효하며 미기록 사항은 미확인이다.
- 설정: 보관된 스크립트, 설정 파일 및 CMake 캐시 참조.
- 입력 데이터: README 이동 목록 참조. 보존 여부를 확정할 수 없는 입력은 미확인이다.

## 4. 전제 조건

원본 파일이 존재하고 사용 중이 아니어야 한다. 재실행은 다음 숫자 폴더에서 경로와 환경을 새로 지정해야 한다.

## 5. 테스트 방법

1. [정리 스크립트](../../build-cleanup_2026-09-15/001/organize.ps1)로 이동 전 파일별 상대 경로, 크기, 수정 시각을 기록했다.
2. 같은 작업에 속한 파일을 이 버전 폴더로 이동했다.
3. 이동 후 파일 목록, 크기, 수정 시각을 비교하고 기존 build 직속 파일은 SHA-256도 비교했다.

## 6. 예상 결과

원본 자료가 손실이나 내용 변경 없이 이동하며, 버전별 자료가 동일한 폴더에 모인다.

## 7. 실제 결과

이동 전후 파일 목록, 크기 및 수정 시각이 일치했다. 기존 build 직속 파일의 SHA-256도 일치했다. [상세 목록](../../build-cleanup_2026-09-15/001/migration-manifest.json)에 기존·현재 경로를 보존했다. 원래 기능 테스트는 재실행하지 않았다.

원본 스크립트와 결과를 보관하여 당시 증거를 유지했다. 과거 스크립트 버전, 실행 순서 또는 원인을 파일명만으로 확정하지 않았다. 보관된 캐시의 이전 경로는 재실행 시 새 구성으로 대체해야 한다.
