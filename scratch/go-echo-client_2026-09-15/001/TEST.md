# 테스트 기록: 최초 Go 클라이언트

- 작업일: 2026-09-15

## 1. 테스트 목적

기본값 입력, 에코 패킷 묶음, 한 세션당 하나의 워커 및 시간 통계를 구현한다.

## 2. 테스트 대상

- 대상 코드: main.go, main_test.go.
- 대상 기능: 최대 32세션의 초기 구현.
- 관련 변경: 신규 도구. 관련 버그는 아래 관찰 결과 참조.

## 3. 테스트 환경

Windows, Go 1.27.1 windows/amd64, 실제 NetLibTest_Echo, 127.0.0.1:26001. 정확한 실행 옵션은 results/*.command.txt 참조.

## 4. 전제 조건

포트 26001이 비어 있어야 한다. 검증에서 생성한 서버만 종료한다.

## 5. 테스트 방법

1. go test main.go main_test.go 실행.
2. 단일 세션, 32세션, 재접속, batch=4096을 실제 서버에서 검사.

## 6. 예상 결과

올바른 에코를 확인하고 수치를 정상적으로 출력한다.

## 7. 실제 결과

[단위 검증](results/go-test.log)은 통과했다. 실제 단일·32세션·재접속은 오류 없이 실행됐다. [큰 묶음 검사](results/large-batch.log)는 원격 연결 종료로 실패했다. 종료 시 NaN/Inf 및 잘못된 p95 출력이 관찰됐다.
